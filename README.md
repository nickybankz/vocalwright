# Vocalwright

Vocal chain plugin for FL Studio (VST3, Windows), by **Nicky Bankz**.
Pick a vibe, set your key, and your vocal comes out tuned, mixed and ready.

## Download

**[Download Vocalwright-Setup.exe](https://github.com/nickybankz/vocalwright/releases/latest/download/Vocalwright-Setup.exe)**

1. Run the installer. Windows may say "Windows protected your PC": click **More info**, then **Run anyway** (the installer isn't code-signed yet).
2. In FL Studio go to **Options > Manage plugins > Start scan**.
3. Put **Vocalwright** in a mixer slot on your vocal track.
4. Set KEY and SCALE to your beat, or press **ANALYZE**, play the vocal for a few seconds, then press **STOP**.
5. Pick a vibe with the arrows, or click the vibe name for the full list.

## What's inside

20 modules: Noise Gate, Foundation, Auto-Tune, Pitch Shifter, De-Esser, Compressor (Clean/Opto/FET), EQ, Saturation, Transients, Exciter, Lo-Fi Radio, Harmony, Doubler, Chorus, Flanger, Auto-Pan, Delay (syncs to FL tempo), Reverb (Studio/Plate/Hall), Cloud, Limiter.

Simple view shows only the modules the vibe uses. Advanced view shows all 20 modules with full controls. Also in Beatwright's Studio tab.
